- Arabic — RTL

## Core Areas
- Students
- Parents
- Fees & Payments

- Qur'an Progress
- Hifz
- Islamic Books & Subjects
- Attendance
- SMS
- Reports
- Notifications
- Settings

## Product Principles
- Premium professional UX
- Enterprise-ready architecture
- Low operating cost
- Local-first data handling
- Secure parent access
- Controlled student deletion
- Payment gateway integration
- Event-based OTP
- Automatic tuition tracking
- Parent notifications
- Regular encrypted backups
- Qur'an content linked to student progress

## Development Rule

Every major development stage must produce an installable APK
and be tested on a second Android device before the next major
stage begins.
